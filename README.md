# 🚀 Skilliant Admin Portal

A modern, responsive, and user-friendly **Admin Portal for the Skilliant platform**, designed to provide administrators with a centralized interface for monitoring and managing platform activities.

## ✨ Features

- 🏠 **Dashboard** — Platform overview with KPI cards, charts, and activity feed
- 👥 **Users Management** — Manage and monitor platform users
- 👷 **Labour Management** — Manage skilled labourers and their information
- 🏢 **Contractor Management** — Manage contractor records and activities
- 🗂️ **Categories Management** — Manage platform categories
- 🧠 **Skills Management** — Manage skills and trades
- 🔍 **Search & Filters** — Quickly find and filter records
- 🪟 **Management Modals** — Add, view, edit, and delete records
- 📊 **Data Visualization** — Interactive dashboard charts and statistics
- 🔔 **Activity Feed** — Monitor recent administrative activities
- 📭 **Empty States** — Clear feedback when no records are available
- 📱 **Responsive UI** — Optimized for desktop, tablet, and mobile devices

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js
- Font Awesome

## 🎨 UI & Design

The portal uses a clean and professional administrative dashboard layout with:

- Responsive sidebar and header
- Modern cards and data tables
- Consistent spacing and typography
- Interactive controls and modals
- Responsive layouts across different screen sizes

## 💾 Data

The application currently uses **mock/static data** to demonstrate dashboard statistics, management records, charts, search, filtering, and administrative workflows.
