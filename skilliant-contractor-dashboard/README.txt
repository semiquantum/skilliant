SKILLIANT LABOUR PORTAL - DAY 1
================================

Project files:
  index.html
  css/style.css
  js/app.js

RUN IN VS CODE (RECOMMENDED)
-----------------------------
1. Extract this ZIP.
2. Open VS Code.
3. File -> Open Folder.
4. Select the extracted folder: skilliant-labour-portal-day1
5. Open index.html.
6. Install the VS Code extension "Live Server" by Ritwick Dey if it is not installed.
7. Right-click index.html -> Open with Live Server.
8. The browser should open at a URL similar to:
   http://127.0.0.1:5500/index.html

IMPORTANT
---------
Do NOT open:
   http://127.0.0.1:5500/index.html/

There must be no slash after .html.
